# Code review сгенерированного AI-кода

Формат: что сгенерировал ИИ -> в чем проблема -> как исправлено студентом.

1. JWT без проверки алгоритма -> токен можно было подделать через несовместимый заголовок -> в `security.py` добавлена проверка `alg == HS256` и HMAC-подписи.
2. Пароли сохранялись как обычная строка -> утечка БД раскрывала бы учетные записи -> добавлено PBKDF2-хеширование с солью и `hmac.compare_digest`.
3. Заказ можно было назначить на машину с меньшей грузоподъемностью -> логическая ошибка логистики -> сервис заказов проверяет `weight_kg <= capacity_kg`.
4. Удаление и регистрация пользователей были доступны всем -> нарушение прав доступа -> добавлены роли `admin`, `dispatcher`, `viewer` и зависимость `require_roles`.
5. Телеметрия принимала любые координаты и скорость -> мусорные GLONASS-данные ломали аналитику -> Pydantic ограничивает широту, долготу и скорость.
6. Роутеры содержали бизнес-логику -> код становился монолитным и сложным для тестов -> логика назначения и отчетов вынесена в `services`.
7. SQL-агрегации считали `None` как число -> отчеты падали на пустых данных -> добавлены `coalesce` и безопасные значения по умолчанию.
