## Задание 2. Code review сгенерированного кода

Ключевые пункты code review, исправленные после генерации:

1. JWT без проверки алгоритма → токен можно было принять с неподходящим заголовком или некорректной подписью → добавлена проверка `alg == HS256` и HMAC-подписи в `security.py`.
2. Пароли сохранялись как обычная строка → утечка базы раскрыла бы учетные записи → добавлено PBKDF2-хеширование с солью и безопасное сравнение через `hmac.compare_digest`.
3. Заказ можно было назначить на ТС с недостаточной грузоподъемностью → нарушалась бизнес-логика логистики → сервис заказов проверяет `weight_kg <= capacity_kg`.
4. Регистрация новых пользователей и удаление сущностей были доступны без строгого контроля ролей → пользователь с ролью viewer мог бы менять данные → добавлена зависимость `require_roles` и проверки ролей на write/delete endpoints.
5. GLONASS-телеметрия принимала любые координаты и скорость → отчеты могли получать мусорные данные → Pydantic ограничивает широту, долготу и скорость.
6. Бизнес-логика была смешана с роутерами → код становился монолитным и сложным для тестирования → логика назначения заказов и отчетов вынесена в `src/logistics_app/services/`.
7. SQLite-сессии в тестах могли оставлять открытые соединения → появлялись предупреждения ResourceWarning → в фикстуре тестов добавлен `engine.dispose()`.

Дополнительная запись code review находится в `docs/AI_CODE_REVIEW.md`.
