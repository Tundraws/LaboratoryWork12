# PROMPT_LOG

Лабораторная работа 12, вариант 13: система управления логистикой.

## Промпт 1

Ты senior Python/FastAPI разработчик. Создай архитектуру веб-приложения для логистики: JWT-аутентификация, роли, CRUD для заказов, маршрутов, транспорта, водителей, прием GLONASS-координат и аналитические отчеты. Код должен быть модульным, с SQLAlchemy, Pydantic и pytest.

Результат: выбрана структура `src/logistics_app`, отдельные `routers`, `services`, `models`, `schemas`, `security`.

## Промпт 2

Сгенерируй Pydantic-модели для предметной области логистики. Добавь ограничения: грузоподъемность больше нуля, координаты в допустимых диапазонах, скорость GLONASS не отрицательная, российский формат госномера ТС.

Результат: добавлены схемы создания и чтения водителей, ТС, маршрутов, заказов и GLONASS.

## Промпт 3

Проведи code review сгенерированного кода как security reviewer. Найди минимум 5 проблем: хранение паролей, JWT, права доступа, валидация координат, бизнес-правила назначения заказа.

Результат: замечания и исправления зафиксированы в `docs/AI_CODE_REVIEW.md`.

## Промпт 4

Сгенерируй pytest-тесты с высоким покрытием для FastAPI-приложения. Нужны positive и negative cases: логин, отсутствие токена, запрет viewer, создание заказа, назначение, отчеты, перегруз машины, 404, 422.

Результат: создана папка `tests`, фикстуры in-memory SQLite и тесты ключевых сценариев.

## Промпт 5

Сгенерируй README для сдачи лабораторной: ФИО, группа, номер лабораторной, вариант, описание программы, технологии, сборка, запуск, примеры API.

Результат: README оформлен под требования Telegram-бота.
